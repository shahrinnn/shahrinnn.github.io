# Shahrin Tabassum — Portfolio (Flat GitHub Pages package)

This release is intentionally **flat**, with all files in one directory to prevent missing assets during GitHub web uploads.

1. Unzip.
2. Go to https://github.com/shahrinnn/shahrinnn.github.io
3. Add file → Upload files. Select **all extracted files**, not the ZIP or its containing folder.
4. Commit changes to main.
5. Wait for Pages deployment, then reload https://shahrinnn.github.io/ with Ctrl+Shift+R.

The portrait is `shahrin-tabassum-portrait-2026.jpg` and the Resume links point to `Shahrin_Tabassum_Resume_Centered_2026.pdf`. These must appear next to `index.html` in the repository root. If GitHub shows a folder next to `index.html`, open it and confirm you uploaded from the correct level.
