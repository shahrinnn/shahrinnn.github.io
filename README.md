# Shahrin Tabassum — Personal Career Portfolio

A lightweight, responsive, static portfolio. No Node.js, npm, or external libraries required.

## Preview locally
Double-click `index.html` or run `python -m http.server 8000` inside the folder and visit `http://localhost:8000`.

## Professional photo
Your professional portrait is already included in `assets/shahrin-tabassum-portrait.jpg` and connected to the home page. No editing necessary.

## Publish to GitHub Pages
1. Sign in to GitHub as `shahrinnn`.
2. Create a **public** repository named exactly `shahrinnn.github.io`.
3. Upload the CONTENTS of this folder (`index.html`, `styles.css`, `script.js`, `assets/`, `files/`, `README.md`) to the repository root, commit to `main`.
4. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, then `main`, folder `/(root)`, and save.
5. Wait for GitHub Pages to finish deploying. Visit `https://shahrinnn.github.io`.
6. After publishing, add that URL to your CV header, GitHub profile and LinkedIn Featured section.
